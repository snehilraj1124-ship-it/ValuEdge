# 💹 ValuEdge — Company Valuation & Financial Modeling Platform

ValuEdge is a full-stack **Company Valuation & Financial Modeling Platform** designed to help users analyze company value using financial modeling techniques such as **Discounted Cash Flow (DCF)** and **Comparable Company Analysis**.

The platform allows users to create company financial profiles, project future free cash flows, calculate enterprise value and equity value, estimate implied value per share, and benchmark companies against comparable businesses.

---

## 🚀 Features

### 🏢 Company Financial Profiles

Create and manage financial profiles containing:

- Company name
- Industry/sector
- Revenue
- EBITDA
- Expected growth
- Capital expenditure
- Working capital investment
- Cash
- Debt
- Shares outstanding

---

### 💰 Discounted Cash Flow Valuation

ValuEdge provides a simplified DCF valuation model including:

- Five-year free cash flow projections
- Discounted cash flow calculations
- Terminal value
- Present value of terminal value
- Enterprise value
- Equity value
- Implied value per share

---

### 📈 Financial Projections

The platform generates projected free cash flows based on:

- Current EBITDA
- Growth assumptions
- Capital expenditure
- Working capital investment

Users can view the projected FCF for each of the five forecast years.

---

### 📊 Comparable Company Analysis

The platform allows users to maintain comparable companies and analyze:

- Revenue multiples
- EBITDA multiples
- Average peer multiples
- Indicative revenue-multiple valuation
- Indicative EBITDA-multiple valuation

Users can add additional comparable companies to the analysis.
